# Танки по кодовой фразе

Слушает микрофон, офлайн распознаёт речь и запускает **World of Tanks**, когда
слышит одну из трёх фраз:

| Фраза | Что слышит распознаватель |
|---|---|
| **Йухан** | `юхан` |
| **Слет Парика** | `след парика` |
| **Витя-кислый** | `ведь кислый` |

Живёт в трее, интернет не нужен. Замеры на этой машине: ~1,8 % одного ядра
в простое и ~200 МБ памяти.

## Почему так странно устроено

Vosk в свободном режиме слышит «Йухан» как «краткое у хэн», а «Витя кислый» —
как «ведь кислый». Поэтому распознаватель ограничен словарём из трёх фраз
(режим грамматики): всё, что не похоже на фразу, помечается `[unk]` и
игнорируется. На тестах это дало 20/20: все три фразы срабатывают, а
«включи музыку погромче» и «где мой кофе» — молчат.

Именно поэтому в `config.json` два поля у каждой фразы:

* `grammar` — слова, которые реально выдаёт распознаватель (из них строится словарь);
* `variants` — как фразу ещё могут написать/произнести.

## Установка

```powershell
cd C:\Documents\deepseek-harness\default-workspace\wot-voice
.\setup.ps1
```

Если Windows ругается «выполнение сценариев отключено в этой системе» —
запускай `install.cmd` (двойным щелчком): он вызывает тот же скрипт в обход
политики выполнения.

Скрипт поставит зависимости, скачает модель распознавания (~45 МБ, в репозиторий
она не входит) и создаст ярлык в автозагрузке (через `pythonw.exe`, без чёрного
окна). Запустить сразу: `.\setup.ps1 -Start` (или `install.cmd -Start`).
Убрать из автозагрузки: `.\setup.ps1 -Remove`.

## Запуск вручную

Двойной щелчок по `start.cmd` — приложение поднимется в трее.

Либо из консоли:

```powershell
python app.py                     # иконка в трее
python app.py --console           # без трея, журнал в консоль
python app.py --simulate "юхан"   # проверить фразу без микрофона
python app.py --list-mics         # какие есть микрофоны
python app.py --calibrate 25      # 25 секунд слушать и показать, что слышит Vosk
```

## Настройка

Всё в `config.json`:

| Поле | Смысл |
|---|---|
| `game_exe` | путь к `WorldOfTanks.exe` |
| `process_name` | имя процесса игры (чтобы не запускать второй клиент) |
| `cooldown_seconds` | пауза между срабатываниями |
| `threshold` | порог схожести, 88 по умолчанию |
| `device` | индекс микрофона из `--list-mics`; `null` — системный по умолчанию |
| `beep` | пискнуть при срабатывании |
| `phrases[].name` | как фраза называется в журнале |
| `phrases[].grammar` | слова для словаря распознавателя |
| `phrases[].variants` | варианты написания |

### Хочу другую фразу

1. `python app.py --calibrate 20` — скажи фразу несколько раз, посмотри в
   `calibrate.txt`, какими словами её слышит Vosk.
2. Возьми самый устойчивый вариант и впиши в `grammar`, а исходную фразу — в
   `variants` и `name`.
3. Перезапусти приложение.

Важно: в `grammar` должны быть слова, которые модель знает. Если вписать
выдуманное слово, Kaldi тихо выкинет его из словаря и фраза перестанет
работать — поэтому и нужна калибровка.

## Если что-то не так

* **Не реагирует.** Проверь `app.log` — там видно каждое распознанное
  «распознано: …». Если микрофон выбран не тот (у тебя их десяток, включая
  Steam и Voicemod), укажи нужный индекс в `device`.
* **Срабатывает не вовремя.** Подними `threshold` до 92–94 или замени фразу
  на более редкую.
* **Игра уже открыта.** Второй клиент не запускается — это проверка по
  `process_name`.
* **Микрофон в простое.** Приложение слушает постоянно, но распознаёт только
  речь; в трее есть пауза.

## Файлы

```

config.json        — настройки и фразы
start.cmd          — запуск в трее двойным щелчком
setup.ps1          — установка и автозагрузка

app.log            — журнал

tools\asr_file.py  — прогнать один wav через распознаватель
```
